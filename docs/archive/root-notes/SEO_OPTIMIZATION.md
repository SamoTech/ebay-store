### 2. Robots.txt
**URL:** https://www.saleh-store.com/robots.txt

**Configuration:**
```
User-agent: *
Allow: /
Disallow: /api/
Disallow: /admin/

Sitemap: https://www.saleh-store.com/sitemap.xml
```

**What it does:**
- Allows all search engines to crawl your site
- Blocks API routes (no need to index)
- Points to sitemap for efficient crawling
