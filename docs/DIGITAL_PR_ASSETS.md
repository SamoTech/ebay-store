# Saleh Store digital PR assets

The purpose of this document is to give external publishers a concrete reason to reference Saleh Store without requesting generic backlinks.

## Public assets

- Production site: https://www.saleh-store.com
- Deal comparison calculator: https://www.saleh-store.com/tools/deal-comparison
- Comparison methodology: https://www.saleh-store.com/research/ebay-deal-comparison-methodology
- Shopping guides: https://www.saleh-store.com/blog
- Category directory: https://www.saleh-store.com/categories

## Pitch angles

1. Marketplace price-comparison methodology
   Explain how headline prices can differ from realistic delivered cost because of shipping, applicable charges, missing accessories, condition, and returns.

2. Buyer-research checklist
   Offer the used smartphone, gaming, camera, dash-cam, and automotive fitment guides as practical reference material.

3. Interactive comparison tool
   The calculator is a lightweight embeddable/reference asset for articles discussing marketplace shopping and total cost.

4. Product-research methodology
   The methodology page documents a reproducible way to normalize product configuration before comparing listings.

5. Data-led future research
   Future Saleh Store studies should publish original datasets with methodology, sample size, date range, and downloadable source data rather than repackaging marketplace pages.

## Backlink quality rule

Do not purchase bulk links, create spun guest posts, or submit the site to irrelevant directories. The objective is to earn references because an asset is useful and independently citeable.
